# Kebabiya

A cinematic, luxury hospitality website for **KABABIYA**, an established multi-outlet restaurant brand based in Kolhapur, Maharashtra, India.

Built with Next.js App Router, Tailwind CSS, Framer Motion, and Lucide React. Designed with an editorial, dark-luxury aesthetic reminiscent of international fine-dining and high-end hotel brands.

---

## 🍽️ About The Brand

Kababiya offers signature dining experiences across three destinations in Kolhapur:
- **Kababiya Kebabs & Biryanis** — Rajarampuri, 13th Lane (Clay oven tandoor mastery & slow-cooked dum biryanis)
- **Kababiya Thalis & More** — Tarabai Park (Authentic Kolhapuri mutton/chicken thalis & regional feasts)
- **Kababiya Kanopy** — Rajarampuri, 9th Lane Ace Arcade (Premier open-air rooftop dining sanctuary)

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, JavaScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Cormorant Garamond & Manrope (Google Fonts)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the active port reported by Next.js) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```

## ☁️ Deploying to Vercel

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/atharvapugade/Kebabiya.git
   git branch -M main
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com/) and click **"Add New..." > "Project"**.
3. Import the `Kebabiya` repository from your GitHub account.
4. Leave Framework Preset as **Next.js** and default build command (`npm run build`).
5. Click **Deploy**. Vercel will build and assign an instant production URL with automatic HTTPS and global CDN.
